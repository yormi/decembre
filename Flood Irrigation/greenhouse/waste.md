# Greenhouse waste — drain main → settling box (week 5)

Absolute quantities for the table row. Per-table drain/overflow drops: `table-water.md`. Supply
side: `water-supply.md`. Zone, drain output: `control.md`.

## Path

All ABS DWV, glued with ABS cement (no primer). Threaded joints only at the valve.

- **Drain main, valved:**
    - each drain drop
    → 2 × 2 × 1½ sanitary tee, branch up
    → 2 po ABS main, ~1 % fall
    → 1 po NO motorized valve at the true low point
    → shared waste run
    → existing settling box.
  2 po carries ~100 L/min half-full vs ~53 needed (1 250 L in ~12 min); the main is the
  limiter, not the valve. Threaded plug at the upstream end for seasonal flush.
- **Overflow line, unvalved:**
    - each overflow drop
    → 1½ sanitary tee, branch up
    → 1½ po ABS line, parallel to the main
    → merges into the waste run just downstream of the NO valve
  (high-tee entry so drain surges can't back up). Passive and always live: the drain
  valve is closed during fill/hold, so standpipes into the valved main would back up
  and defeat the level cap.
- Geometry: greenhouse 108 pi, valve at the far end → ~108 pi of each main, then one
  shared ~80 pi run. ~1 % = ~33 cm over the mains + ~25 cm over the run; if the fall
  isn't there, upsize the shared run to 3 po at ~0,5 %. No bellies.
- Buried waste run: sand bedding, grade by string or laser before backfill, cleanout
  wye + riser at the upstream end, valve + merge accessible.
