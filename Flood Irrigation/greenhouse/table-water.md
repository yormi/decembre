# Table water — ports + drops (flood tables)

Add-on to `table.md`. Shared kit (station, header, mains): `water-supply.md`, `waste.md`.
Port design: `../tray-ports.md`. Fill-drop design: `../tray-fill-drop.md`.

Each xTray is hydraulically independent: the overflow standpipe (≈ 2,5 po) sets its own
level, so only each 3×6 footprint must be level, never the whole row.
