# Greenhouse — build steps

When: `timeline.md`. Spec: `../greenhouse/`. Receiving checklists: `../receiving/greenhouse/`.
`· Richard` = Richard can do it alone.


## Waste run · Richard

- Dig the waste run trench, greenhouse valve end → existing settling box, ~80 ft

- Bed with sand → grade 1 %

- Fit the Uniseal in the settling box

- Glue + lay the 2 in waste run → into the Uniseal

- Glue the cleanout wye + riser + plug at the upstream end

- Glue the vertical drop stub at the greenhouse end

- Backfill the trench


## Tables + ports · Richard

- Set 15 xTrays on the benches

- Drill + fit drain and overflow ports, 15 xTrays

- Drill + fit fill-drop grommets, 15 xTrays


## Drain line · Richard

- Glue the 2 in drain main with 16 tees + bushings

- Zip-tie the drain main to the table legs, 1 % fall to the valve

- Thread the 1 in NO valve at the low point → vertical drop + merge tee

- Fit drain vinyl drops, 16 xTrays


## Overflow line · Richard

- Glue the 1½ in overflow line with 16 tees + bushings

- Zip-tie the overflow line to the table legs, 1 % fall → merge tee

- Fit overflow vinyl drops, 16 xTrays


## Supply + fertigation station

- Glue a tee into the pump manifold (`../for-later.md`)

- Plumb the tee → Orisha fill valve → Dosatron A

- Plumb Dosatron A → B → filter → check valve

- Plumb the 10 psi regulator → 1½ in header

- Set up stock A drum + stock B bucket → set the Dosatrons


## Header + fill drops · Richard

- Zip-tie the 100 ft header to the table legs → cap the far end (male adapter + threaded cap)

- Punch + fit 16 fill drops


## Control

- Mount + wire the Orisha: fill valve, drain valve, tensiometer


## Commissioning

- Flush + leak-test the supply

- Run one flood cycle → check leaks, drain-back, overflow level

- Time one drop → program the zone
