## First rack — one existing west + north rack, plants on

- Drill + fit drain + overflow ports, 5 trays

- Drill + fit the fill-drop grommet, 5 trays

- Per tier: lift the flats → set tray → shim (pour 5 L, drains to port) → flats back

- Glue the downpipe: tees per tier → bushings → adapters → zip-tie to the post

- Glue the horizontal line: elbows, stubs, tier-1 tees → spa flex → collector tee

- Drain drops: port → vinyl → adapter → valve → adapter → vinyl → downpipe tee, 5

- Overflow drops: port → vinyl → downpipe tee, 5

- Fill drops: barbed valve → tube 1,4 m → grommet → elbow inside, aimed down, 5

- Wire the drain valves, 18/2 + WAGO · needs Orisha 18/2 wire
