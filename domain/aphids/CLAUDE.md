# domain/aphids — aphid control model

Split so each file answers one kind of question.

- `aphids.md` — **the pest and the program.** Population arithmetic,
  the wash-line residue standard, program sizing, cadence design,
  release conditions, spray compatibility, supplier and cost
  structure, expected results, failure modes.
  **Reach for this when:** setting rates, cadence or coverage, or
  checking whether a spray or a greenhouse setting is compatible.

- `predators-comparison.md` — **choosing between agents.** The two
  properties that decide fit, speed and cost tables, predator-days
  per dollar, behaviour on a clean crop, fragility, combinations,
  agents rejected without a full entry.
  **Reach for this when:** picking or swapping a backbone, or
  weighing one agent against another.

- one file per agent — `aphidoletes.md`, `chrysoperla.md`,
  `micromus.md`, `nabis.md`, `adalia.md`, `parasitoids.md`.
  Form supplied, onset, feeding stages, conditions, rates, prices,
  failure modes, verdict.
  **Reach for this when:** working with that agent specifically.

Prices are Canadian quotes, 2026-08. They age — revisit the
per-agent files after any new quote, not the protocol.

Protocol: `../../protocol/aphids-biocontrol.md`.
