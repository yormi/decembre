# Nursery floor drain — sewer tie-in

Destination for the rack collectors (`waste.md`). Ties into the existing
greenhouse → property sanitary sewer line, ~15 pi from the
nursery, invert ~5 pi below grade. Municipal sewer: no
volume limit.

- Floor drain with P-trap set in the nursery floor (concrete
  collar) → cleanout wye + riser inside the wall → 3 po ABS
  DWV → 45° drops to depth just outside the wall → ~2 % run
  → 4 × 3 po sanitary wye on the existing line, 2 Fernco,
  branch pointing downstream. Backwater valve (clapet
  anti-retour) on the branch in an access box. Sand bedding,
  hand backfill around the pipe.

- Shallow segment (wall → depth) drains dry after every
  cycle → no insulation. Trap indoors, heated. Off-season:
  jug of water weekly or plug the drain.

- Collectors discharge ABOVE the grate — air
  gap, never sealed in.

- Dig before ground freeze (October).
